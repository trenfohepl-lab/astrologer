Firebase Realtime Database

How to enable (2 minutes)
  1. Create a free Firebase project → Build → Realtime Database → Create.
  2. Copy the database URL (looks like https://xxxx-default-rtdb.firebaseio.com).
  3. In config.js set firebase.enabled: true and paste the URL into databaseURL.
  4. Rules: allow public read on siteConfig. For write, require auth and put a token in authToken — never leave write open to the public.

Change Admin PIN

The PIN is a convenience lock stored in this browser. For real security on a public site, also protect admin.html (e.g. Vercel password protection) and use Firebase auth rules.
